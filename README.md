# How to run
The core RISC-V emulator is in riscv, all you need to do are the following, broadly.
1. Install fnm, a manager of node versions. It's available on https://github.com/Schniz/fnm
2. Run 'fnm install' in the root of this repo
3. Run 'fnm use' in the root of this repo
4. Run 'cd riscv' to move into the right directory
5. Run 'npm i' to install all the stuff you need
6. Run 'npm run dev' to run it, and hit the website it launches.
