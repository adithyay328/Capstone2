# How to run
The core RISC-V emulator is in riscv, all you need to do are the following, broadly.
1. Guarantee that your node version is the same as the one we reccomend, we reccomend fnm since it runs on everything
2. Run 'npm ci' to install all the stuff you need
3. Run 'npm run dev' to run it, and hit that website.

## Getting the right nodeJS version
1. Install fnm, a manager of node versions. It's available on https://github.com/Schniz/fnm
2. Run 'fnm install'
3. Run 'fnm use'
